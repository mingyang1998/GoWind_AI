## 修对话历史跨页丢失 bug
- 根因：`load` 辅助函数 `{...fallback, ...JSON.parse(v)}` 对数组 fallback 会把数组展成对象 → Array.isArray false → 返回 []；对话页重新挂载时 convs 被清空，保存 effect 又把空 [] 写回 localStorage，连锁清空追踪页数据
- 修：chat 页 convs 初始化改直接 JSON.parse（避开 load 的对象展开），与 traces 页 loadConvs 一致。provider 是对象仍用 load(merge) 无害
