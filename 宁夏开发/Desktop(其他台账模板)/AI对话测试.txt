### 💡 如何在 Excel 中自行完成分组（免代码）
如果您需要在 Excel 中直接生成包含具体 IP 明细的分组表，可以按照以下 3 步操作：

1. **提取网段**：
   在 `存活_ip-952` 表的 C 列（假设 A 列是 IP，B 列是计数）新建一列命名为“**所属网段**”。
   在 C2 单元格输入以下公式并下拉填充：
   ```excel
   =LEFT(A2, FIND(".", A2, FIND(".", A2, FIND(".", A2)+1)+1)-1) & ".0/24"
   ```
   *(该公式会自动将 `10.217.212.122` 转换为 `10.217.212.0/24`)*

2. **创建数据透视表**：
   选中 A、B、C 三列 -> 点击顶部菜单栏的 **插入** -> **数据透视表**。

3. **拖拽字段**：
   - 将“**所属网段**”拖入 **行** 区域。
   - 将“**ip**”拖入 **值** 区域（设置为“计数”）。
   - 右键点击任意数字 -> **排序** -> **降序**，即可得到完美的网段分组报表。

### 🐍 Python 自动化处理脚本
如果您后续有更大的数据量或需要定期处理，可以使用以下 Python 脚本（依赖 `pandas`），一键读取 Excel 并导出网段分组结果：

```python
import pandas as pd

# 1. 读取 Excel 文件中的 '存活_ip-952' 表
file_path = '存活地址（中卫）.xlsx'
df = pd.read_excel(file_path, sheet_name='存活_ip-952')

# 2. 提取 /24 网段 (按 '.' 分割后取前 3 段)
df['网段'] = df['ip'].apply(lambda x: '.'.join(str(x).split('.')[:3]) + '.0/24')

# 3. 按网段分组统计存活 IP 数量
subnet_stats = df.groupby('网段').agg(
    存活IP数量=('ip', 'count')
).reset_index()

# 4. 降序排列
subnet_stats = subnet_stats.sort_values(by='存活IP数量', ascending=False)

# 5. 导出结果
subnet_stats.to_excel('网段分组统计结果.xlsx', index=False)
print("✅ 网段分组统计完成，已保存为 '网段分组统计结果.xlsx'")
```
